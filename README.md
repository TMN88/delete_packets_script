# Packets Delete for OpenWrt

Интерактивный деинсталлятор только для компонентов из [TMN88/install_packets_script](https://github.com/TMN88/install_packets_script).

## Запуск

Подключитесь к роутеру по SSH под `root` и выполните:

```sh
wget -O /tmp/delete-packets.sh https://raw.githubusercontent.com/TMN88/delete_packets_script/main/delete-packets.sh && sh /tmp/delete-packets.sh
```

## Что удаляет

Скрипт обнаруживает только компоненты, доступные через меню Install Packets Script:

- Podkop
- Forkop
- AmneziaWG (пакеты AmneziaWG, не конфигурации туннелей)
- Zapret Manager / классический Zapret
- Zapret2 Routerich
- классический Zapret2, установленный вручную в `/opt/zapret2`
- AWG Test / Podkop VPN Failover
- Site Checker
- русская локализация LuCI (`luci-i18n-base-ru`)
- дополнительные USB-модули из пункта установщика

Список компонентов показывается только если они обнаружены. Можно выбрать конкретные пункты или `A` для всех обнаруженных компонентов. Перед изменениями показывается план, а выполнение требует ввести `DELETE`.

## Важные ограничения

- **Системные пакеты OpenWrt не отображаются и не удаляются.** Скрипт не предлагает удаление произвольных пакетов.
- Удаляются только перечисленные пакеты выбранного компонента, без `--autoremove`; зависимости намеренно не удаляются автоматически.
- Для классического Zapret2 каталог `/opt/zapret2` остаётся нетронутым, пока пользователь отдельно не подтвердит его удаление.
- При удалении AmneziaWG конфигурации интерфейсов/туннелей могут сохраниться в OpenWrt; перед удалением проверьте их, если они нужны.
- Перед запуском рекомендуется сделать резервную копию конфигурации.
- Скрипт прошёл только статическую проверку shell-синтаксиса; функционально на физическом роутере не тестировался. Имена файлов и пакетов сторонних установщиков могут меняться.
