# Packets Delete for OpenWrt

Интерактивный скрипт для удаления установленных пакетов в OpenWrt через `apk` (OpenWrt 25.12+) или `opkg` (OpenWrt 24.10).

## Запуск

Подключитесь к роутеру по SSH под `root` и выполните:

```sh
wget -O /tmp/delete-packets.sh https://raw.githubusercontent.com/TMN88/delete_packets_script/main/delete-packets.sh && sh /tmp/delete-packets.sh
```

## Возможности

- Показывает список установленных пакетов и нумерует строки.
- Позволяет удалить выбранные пакеты, введя номера через пробел или запятую.
- Пункт `A` выбирает все пакеты, кроме защищённых системных пакетов.
- Перед изменениями показывает план и требует ввести `DELETE`.
- Использует `apk del` или `opkg remove` в зависимости от системы.
- Для известных дополнительных компонентов останавливает/отключает службы и очищает связанные файлы конфигурации и остатки вне пакетного менеджера.
- Очищает кэш менеджера пакетов.
- Не предлагает перезагрузку при обычном удалении приложений. Ядро и пакеты `kmod-*` намеренно защищены.

## Защита и ограничения

Скрипт рассчитан на OpenWrt 24.10 (`opkg`) и 25.12 (`apk`). Системные пакеты, ядро, пакеты `kmod-*` и `luci-i18n-base-ru` исключены из выбора. `УДАЛИТЬ ВСЁ` означает все незашищённые пакеты, а не сброс роутера к заводским настройкам.

Для сторонних компонентов известные файлы конфигурации и служб очищаются отдельно. У неизвестных пакетов очистку выполняет пакетный менеджер; произвольные пользовательские файлы не удаляются автоматически. Это сделано намеренно: безопасно определить владельца всех файлов, созданных сторонними установщиками, универсальным способом невозможно.

**Важно:** перед использованием рекомендуется сделать резервную копию конфигурации OpenWrt. Команда удаления пакетов может затронуть сетевые сервисы, VPN или веб-интерфейс — внимательно проверяйте итоговый список. Скрипт пока не проходил функциональное тестирование на физическом роутере; перед массовым удалением сначала протестируйте выбор нескольких конкретных пакетов.
